# ห้องแล็บมรสุมกับฤดูของประเทศไทย

สื่อการสอนภาษาไทยสำหรับนักเรียนประถมศึกษา เปิดเป็นเว็บไซต์ผ่าน GitHub Pages หรือเปิดไฟล์ `index.html` ในเครื่องได้ ใช้งานออฟไลน์ได้ ไม่ต้องติดตั้งแพ็กเกจหรือสั่ง build

## สิ่งที่นักเรียนทำได้

- เลื่อนช่วงเดือนเพื่อสังเกตมรสุมตะวันตกเฉียงใต้ มรสุมตะวันออกเฉียงเหนือ และช่วงเปลี่ยนผ่าน
- สลับระหว่างแผนที่ผลกระทบกับภาพกลไกการหมุนเวียนอากาศ
- เลือกพื้นที่เพื่อเปรียบเทียบไทยตอนบนและภาคใต้สองฝั่ง
- สร้างเหตุการณ์สมมุติโดยปรับกำลังลม ไอน้ำต้นทาง การรับไอน้ำจากอ่าวไทย และผลของแนวเขา
- ทำภารกิจ ตรวจคำตอบ บันทึกผล และดาวน์โหลด CSV
- ใช้โหมดสอนหน้าชั้น และพิมพ์ผลหรือบันทึกเป็น PDF ผ่านคำสั่งพิมพ์ของเบราว์เซอร์

## ไฟล์ในชุดนี้

```text
index.html     หน้าเว็บหลัก รวมภาพ CSS และ JavaScript ไว้ในไฟล์เดียว
README.md      คำอธิบายสื่อและวิธีเผยแพร่
.nojekyll      ให้ GitHub Pages เผยแพร่ไฟล์สื่อแบบ static โดยตรง
```

## อัปโหลดผ่านเว็บไซต์ GitHub

1. หากได้รับชุดนี้เป็น ZIP ให้ **แตก ZIP ก่อน** ไม่ใช่อัปโหลดไฟล์ ZIP เป็นหน้าเว็บ
2. สร้าง repository ใหม่ แนะนำชื่อ `thailand-monsoon-lab` หากต้องการใช้ GitHub Pages แบบสาธารณะในบัญชี GitHub Free ให้เลือก **Public**
3. ใน repository เลือก **Add file → Upload files** (repository ว่างอาจแสดงลิงก์ **uploading an existing file**)
4. อัปโหลด `index.html`, `README.md` และ `.nojekyll` จากโฟลเดอร์นี้ แล้วเลือก **Commit changes**
5. ตรวจว่า `index.html` อยู่ **ระดับแรกของ repository** ดังตัวอย่างด้านล่าง อย่าอัปโหลดโฟลเดอร์ครอบซ้อนเข้าไปอีกชั้น

```text
thailand-monsoon-lab (repository)
├── index.html
├── README.md
└── .nojekyll
```

## เปิดเว็บไซต์ด้วย GitHub Pages

1. ไปที่ **Settings → Pages** ของ repository
2. ใต้ **Build and deployment** ตั้ง **Source → Deploy from a branch**
3. เลือก branch **main** และโฟลเดอร์ **/(root)** แล้วกด **Save**
4. รอให้การเผยแพร่สำเร็จ แล้วใช้ URL ที่ GitHub แสดงในหน้า Pages เพื่อส่งให้นักเรียน

สำหรับ repository ชื่อข้างต้น URL โดยทั่วไปมีรูปแบบ:

```text
https://YOUR-USERNAME.github.io/thailand-monsoon-lab/
```

`YOUR-USERNAME` เป็นข้อความตัวอย่าง ต้องใช้ชื่อบัญชี GitHub จริงของผู้เผยแพร่ URL ที่ควรใช้ยืนยันคือ URL ที่ GitHub แสดงหลังเผยแพร่สำเร็จ

หาก branch ของคุณใช้ชื่ออื่นแทน `main` ให้เลือก branch ที่มี `index.html` อยู่จริง หากเปิดได้เป็น README หรือพบหน้า 404 ให้ตรวจว่าไฟล์สะกดเป็น `index.html` ตัวเล็ก และอยู่ตรงกับ branch/โฟลเดอร์ที่เลือก

## ใช้ในห้องเรียน

เปิด `index.html` ด้วย Chrome, Edge, Firefox หรือ Safari แล้วเลือกสถานการณ์เริ่มต้น ให้ผู้เรียนทำนายก่อนเปลี่ยนเงื่อนไข ทดลองครั้งละหนึ่งตัวแปร และบันทึกผลเพื่อเทียบกัน ภายในสื่อมีคู่มือครูและคำถามประเมิน

บันทึกผลอยู่ในเบราว์เซอร์ของแต่ละเครื่อง ไม่ได้ส่งเข้า GitHub ไม่มีฐานข้อมูลส่วนกลาง เมื่อเปลี่ยนเครื่อง เบราว์เซอร์ หรือ URL บันทึกเดิมอาจไม่ปรากฏ ควรดาวน์โหลด CSV เพื่อเก็บผลถาวร

## ขอบเขตของสื่อ

นี่คือแบบจำลองเชิงแนวคิด ไม่ใช่พยากรณ์อากาศ ช่วงฤดูเป็นค่าโดยประมาณ ดัชนีฝน 0–4 เป็นค่าเปรียบเทียบในแบบจำลอง ไม่ใช่ปริมาณฝนจริงหรือโอกาสฝนตก แผนที่เป็นภาพสังเขปสำหรับการสอน รายละเอียดสมมุติฐานและแหล่งข้อมูลมีอยู่ท้ายหน้าเว็บ
